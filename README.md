# LUMI — демо лендинга салона красоты

Адаптивный одностраничный сайт для демонстрации потенциальному заказчику.

## Что реализовано

- Главный экран и CTA онлайн-записи
- Услуги с примерными ценами, фильтр по категориям, выбор услуги
- Мастера с демонстрационными именами и фотографиями
- Блок отзывов (тексты явно обозначены как демонстрационные)
- Контакты, часы работы и демонстрационная карта
- Мобильное меню и фиксированная кнопка записи на телефоне
- Модальное окно записи с выбором услуги/мастера, только демонстрация: никаких реальных заявок не отправляет

## Стек

HTML, CSS, JavaScript без сборщика и внешних JS-зависимостей. Шрифты Google Fonts, демонстрационные изображения Unsplash, карта OpenStreetMap.

## Запуск

Откройте `index.html` в браузере. Интернет потребуется для фотографий, шрифтов и карты.

## Публикация на GitHub Pages

1. Создайте новый **public** репозиторий `lumi-beauty-demo` (или другое название).
2. Загрузите `index.html`, `README.md`, `.nojekyll` в корень репозитория.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` → `/ (root)` → Save.
4. После публикации сайт появится по адресу `https://<ваш-логин>.github.io/lumi-beauty-demo/` (если выбрано это название репозитория).

## До запуска реального сайта

- Уточнить настоящее название салона, фото, услуги, цены, адрес, часы работы, контакты и реальные согласованные отзывы.
- Подключить YCLIENTS: получить индивидуальный код виджета или ссылку для записи у салона; заменить демо-сценарий записи. Для произвольной кнопки следовать официальной инструкции https://support.yclients.ru/251.
- Проверить работоспособность онлайн-записи и отображение на разных телефонах.
- Подключить реальную карту салона и базовые SEO-данные.
- Настроить домен/хостинг заказчика (текущий репозиторий — только демо).

**Не использовать демонстрационные сведения как реальные данные коммерческого салона.**
