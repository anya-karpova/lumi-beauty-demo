# LUMI — сайт студии красоты

Сделала адаптивный одностраничный сайт для студии красоты. Хотелось, чтобы он выглядел аккуратно, легко воспринимался и был удобным в первую очередь на телефоне.

## Что есть на сайте

- Главная страница с информацией о студии и кнопкой записи
- Список услуг с ценами и фильтрацией по категориям
- Карточки мастеров
- Отзывы клиентов
- Контакты, время работы и карта
- Адаптивная версия для телефонов и компьютеров
- Окно записи, в котором можно выбрать услугу и мастера

## Технологии

HTML, CSS и JavaScript. Без фреймворков и сложной настройки — весь сайт находится в `index.html`.

## Как запустить

Достаточно скачать проект и открыть `index.html` в браузере. Для загрузки фотографий, шрифтов и карты нужен интернет.

## О проекте

Пока это демонстрационная версия: название студии, имена мастеров, цены, отзывы и контакты используются как примеры. Форма записи показывает интерфейс, но не отправляет заявки.

Для реального салона можно заменить материалы на настоящие и подключить запись через YCLIENTS или отправку заявок в Telegram.
